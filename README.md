# HDU二课答疑助手
***just for fun***
## 🌟 项目核心亮点

### 1. 极致的“零后端”架构与单文件交付
抛弃了传统校园系统沉重复杂的服务器和数据库依赖。整个应用被打包为纯粹的单个 `index.html` 文件，体积轻量。不仅部署成本为 0，更实现了**“断网也能用”**的极致稳定性。

### 2. 严防“AI 幻觉”的数据纪律
针对大语言模型容易在学分规则上“胡编乱造”的痛点，本项目放弃了直接调用大模型 API，转而采用**“本地知识库精准匹配 + 严格 Schema 校验”**。通过人工介入剔除矛盾数据（如 `needsReview` 机制），确保输出的每一张办事卡都事实准确、可溯源。

### 3. 极佳的移动端阅读体验与“截图友好”设计
摒弃了长篇大论的“小作文”式答疑。将复杂的二课规则拆解为“一句话结论、操作步骤、所需材料、去哪办”的结构化卡片。**高度适配手机屏幕**，便于截屏

### 4. 严苛环境下的前端健壮性
专门针对微信内置浏览器、隐私模式等严苛环境进行了兼容性重构。采用纯 DOM 控制替代传统路由跳转以绕过微信沙箱限制；针对本地存储被禁用的极端情况，实现了 `localStorage -> sessionStorage -> 内存变量` 的三级降级兜底，**保证产品在任何环境下都不白屏、不崩溃**。
